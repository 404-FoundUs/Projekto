the issue comes with the docker file inside the project ! usually the docker file should be near the project file like this 

if there is a seperate folder manage it like this 
```
  app:
    build:
      context: ./../Projekto-backend
      dockerfile: ./../Projekto-backend/Dockerfile
```
use context.

```
project-root/
├── docker-compose.yml
├── Dockerfile
└── myapp/          ← Spring project lives here
    ├── src/
    └── pom.xml
```   

If we have our env file on seperate directory we mush tell the docker compose about the location of env.
```
docker compose --env-file ../.env/.env.development up -d
```
